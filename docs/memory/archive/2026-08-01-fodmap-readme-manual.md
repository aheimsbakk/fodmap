User preference (2026-08-01): the README is a user documentation / user
manual, not a developer-centric doc. Write it in Norwegian bokmål
(klarpråk, user-facing) with the manual content dominant (opening the page,
search, text size, colors, content source); keep dev reference (tests,
scripts, config, license) compact at the end. Script docs must still cover
purpose, arguments, and usage examples (RULES §24).
